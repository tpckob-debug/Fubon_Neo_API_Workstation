# Fubon_Neo_API_Workstation
# 富邦新一代API
🚀 富邦 Neo API 全功能交易與帳戶管理工作站
(Fubon Neo API Trading & Accounting Desktop Workstation)

本專案是一個基於 Python Tkinter 與 fubon_neo SDK 開發的桌面端自動化交易介面（GUI）。提供完整的證券與期權下單控制台、雲端智慧條件單洗單、即時 WebSocket 行情監聽，以及多盤別帳務與庫存部位即時查詢功能。

✨ 核心特色功能
1. 🔐 帳號管理與權限自動分流
證券 / 期權雙通道切換：登入時自動辨識帳號類型（stock / futopt），並在下單與帳務頁面提供獨立切換選單。

安全性驗證：支援富邦電子憑證（.pfx / .p12）檔名驗證與動態加解密登入。

2. 🔍 REST API 商品真實代碼搜尋
全市場即時撈取：支援證券（TWSE / TPEx）與期權（TAIFEX 期貨與選擇權）全市場商品檔。

智慧字串模糊比對：自動處理「臺/台」字元替換，支援依關鍵字（如：台指、微台、2330）快速搜尋。

一鍵複製與匯出：點擊即可複製商品代碼至剪貼簿，並支援將搜尋結果匯出為 CSV 檔。

3. ⌨️ 綜合下單與智慧條件單控制台
單式單下單：依據選取帳號類別自動切換 Order (證券) 或 FutOptOrder (期權) 物件，支援限價/市價、ROD/IOC/FOK，並依據交易時間自動判別日夜盤。

跨月/選擇權複式單：自動識別第一隻腳代碼屬性（TMF 期貨 / TXO 選擇權），自動對齊 Future / Option 日夜盤 MarketType。

雲端智慧條件單 (Single Condition)：

支援設定洗單開始與結束期限（預設帶入 14 天）。

動態封裝 Condition 物件，自動解析 comparison 觸發條件（GTE / LTE）與價格。

4. ⚡ 行情 WebSocket 監聽模組
雙模式支援：提供 Speed (極速 mode, 逐筆成交/五檔) 與 Normal (一般 mode, K線/統計) 模式切換。

自動退訂映射 (Smart Fallback)：記錄 WebSocket 訂閱 sub_id 與頻道 Key，確保退訂時不會因證券缺少 afterHours 欄位而失敗。

5. 📊 帳務與部位查詢控制台
權益數 / 保證金查詢：自動比對期權權益數與證券未實現損益。

庫存部位查詢：自動串接 query_single_position 與 query_hybrid_position 撈取單式與複式部位。

全市場成交回報自動輪詢：一鍵同時輪詢日盤期貨、夜盤期貨、日盤選擇權與夜盤選擇權（Future / Option / FutureNight / OptionNight），並將全當日成交紀錄匯總於表格中顯示。

🛠️ 環境需求與套件安裝
請確保您的開發環境支援 Python 3.10 或更高版本。

🚀 快速開始
直接執行主程式即可啟動 GUI 介面：

操作步驟：
分頁 1（登入與帳號）：填入身分證字號、登入密碼、憑證路徑及憑證密碼，點擊「執行 SDK 登入」。
分頁 2（商品代碼查詢）：可輸入關鍵字查詢台指期、微台或個股代碼。
分頁 3（綜合下單與條件單）：選擇操作帳號後，即可進行單式單、複式價差單或雲端智慧條件單掛單。
分頁 4（行情 WebSocket）：啟動 WebSocket 連線後，即可輸入代碼訂閱逐筆成交或五檔行情。
分頁 5（帳務與部位查詢）：切換欲查詢帳號，點擊即可即時取得權益數、未平倉部位與當日成交明細。
